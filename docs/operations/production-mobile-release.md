# Production mobile release (Android)

## Build

Requires `ORA_GOOGLE_PLACES_API_KEY` in the environment (client Places key only).

```bash
cd mobile
# Uses mobile/.production_api_url when ORA_API_BASE_URL unset
chmod +x scripts/build_production_release.sh
export ORA_GOOGLE_PLACES_API_KEY=...
./scripts/build_production_release.sh both   # apk | appbundle | both
```

Dart defines:

- `ORA_ENV=production`
- `ORA_APP_CHECK=true`
- `ORA_API_BASE_URL=https://ora-auth-service-2zmxvrrs7a-uc.a.run.app/v1` (or current prod URL file)
- `ORA_GOOGLE_PLACES_API_KEY=...`

Release mode uses `AndroidPlayIntegrityProvider()` (`kReleaseMode` → no debug App Check provider).

## Signing

1. Provision an **authorized** upload keystore (not generated by automation in-repo).
2. Copy `android/key.properties.example` → `android/key.properties` (gitignored).
3. Set `storeFile` to the keystore path (e.g. `app/upload-keystore.jks`, also gitignored).

Release builds **fail** without `key.properties` (no debug-signed release artifacts).

After first release-signed build, register the **release certificate SHA-256** on Firebase Android app `1:498169438285:android:3b100b1c7a7248f1ddbc04` (keep existing debug SHAs for dev).
