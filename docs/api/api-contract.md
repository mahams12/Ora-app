# ORA — API Contract

**Base URL:** `https://api.ora.app/v1`  
**Protocol:** HTTPS only  
**Authentication:** Bearer token (Firebase ID token) + X-Firebase-AppCheck header  
**Content-Type:** application/json  
**Versioning:** URL path versioning (`/v1/`, `/v2/`)

## Common Request Headers

```
Authorization: Bearer {firebase_id_token}
X-Firebase-AppCheck: {app_check_token}
Content-Type: application/json
Accept: application/json
Idempotency-Key: {key}        (required on business-critical mutating endpoints)
X-Request-Id: {uuid}          (generated by client; used for tracing)
X-Client-Version: 1.0.0       (app version)
X-Platform: android | ios
```

## Common Response Format

### Success

```json
{
  "data": { ... },
  "requestId": "req_abc123",
  "timestamp": "2026-08-18T07:30:00Z"
}
```

### Error

```json
{
  "error": {
    "code": "ALREADY_ASSIGNED",
    "message": "This ride already has an assigned driver.",
    "details": {},
    "requestId": "req_abc123",
    "timestamp": "2026-08-18T07:30:00Z"
  }
}
```

## Standard Error Codes

| HTTP | Code | Meaning |
|---|---|---|
| 400 | VALIDATION_ERROR | Request body fails validation |
| 401 | UNAUTHENTICATED | Missing or invalid JWT |
| 403 | UNAUTHORIZED | Authenticated but not permitted |
| 403 | APP_CHECK_FAILED | Invalid App Check token |
| 404 | NOT_FOUND | Resource does not exist |
| 409 | RIDE_CONFLICT | Generic ride concurrency conflict |
| 409 | ALREADY_ASSIGNED | Ride already has a driver (select or late offer) |
| 409 | STATE_CONFLICT | Invalid state transition attempted |
| 409 | VERSION_CONFLICT | Optimistic concurrency failure |
| 409 | IDEMPOTENCY_KEY_REUSED | Same idempotency key reused with different payload |
| 409 | OFFER_ALREADY_EXISTS | Driver already has a non-terminal offer for this requestVersion |
| 422 | FARE_OUT_OF_BOUNDS | Offer outside OfferBoundPolicy |
| 422 | OFFER_EXPIRED | Offer TTL elapsed; cannot assign |
| 422 | OFFER_STALE | Offer requestVersion mismatch |
| 422 | OFFER_NOT_SELECTABLE | Offer status is not PENDING |
| 422 | OFFER_AMOUNT_MISMATCH | Accept type amount ≠ passengerOffer |
| 422 | DRIVER_NOT_ELIGIBLE | Driver not dispatched/eligible for this request |
| 422 | INVALID_STATE_TRANSITION | Cannot make this transition from current state |
| 429 | RATE_LIMITED | Too many requests |
| 500 | SERVER_ERROR | Internal server error |
| 503 | SERVICE_UNAVAILABLE | Degraded mode or maintenance |

## Pagination

List endpoints use cursor-based pagination:

```json
{
  "data": {
    "items": [...],
    "nextCursor": "eyJjcmVhdGVkQXQiOiIyMDI2LTA4LTE4VDA3OjMwOjAwWiJ9",
    "hasMore": true,
    "total": 148
  }
}
```

Query: `?cursor={nextCursor}&limit=10`
